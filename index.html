BUC Workspace

Software de Produtividade, Gestão de Conhecimento e Rede Neural de Projetos.

Visão Geral de Privacidade: O BUC Workspace foi arquitetado com privacidade em primeiro lugar. Os seus dados, notas e arquivos pertencem exclusivamente a você e são armazenados no seu próprio dispositivo e na sua conta do Google Drive.

1. Política de Privacidade

Esta Política de Privacidade descreve como o BUC Workspace coleta, utiliza e protege suas informações ao utilizar nossos serviços e nossa integração com a API do Google Drive.

1.1 Dados Coletados

  • Informações de Perfil do Google: Nome de exibição, endereço de e-mail e foto de perfil (obtidos através dos escopos userinfo.profile e userinfo.email) para identificação do autor em publicações na rede.
  • Acesso ao Google Drive: Utilizamos o escopo restrito https://www.googleapis.com/auth/drive.file. Isso significa que o BUC Workspace só pode acessar, criar e modificar os arquivos e pastas que o próprio aplicativo criou (como pacotes .pmz e pastas de círculos). O aplicativo NÃO tem acesso a nenhum outro arquivo pessoal ou documento pré-existente no seu Google Drive.

1.2 Uso das Informações

Os dados acessados são utilizados exclusivamente para:

  • Permitir o salvamento, sincronização e compartilhamento de projetos de notas criados pelo usuário.
  • Criar atalhos na pasta de exploração global (Global Explore) quando o usuário escolhe publicar um projeto.
  • Exibir o nome e avatar do criador no feed de publicações.

Nenhum dado do usuário é vendido, transferido ou compartilhado com terceiros para fins de marketing ou publicidade.

2. Conformidade com a Política de Dados do Usuário dos Serviços de API do Google

O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo pelo BUC Workspace cumprirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

3. Termos de Serviço

Ao utilizar o BUC Workspace, você concorda que:

  • Você é o único responsável pelo conteúdo que cria e decide compartilhar publicamente na rede ou em círculos privados.
  • É proibido utilizar a plataforma para distribuir materiais ilegais, maliciosos ou protegidos por direitos autorais sem a devida autorização.
  • O aplicativo é fornecido "como está", visando oferecer uma experiência fluida de gerenciamento de conhecimento e código.

4. Contato do Desenvolvedor

Para dúvidas, suporte ou solicitações de exclusão de dados vinculados, entre em contato através do e-mail do desenvolvedor cadastrado no Google Cloud Console.
